# Goal archetypes

Enumerated set of goal types. Strategy cards declare compatibility
against these ids. Match files set exactly one `goal_type` from this
list.

Add new ids sparingly — proliferation defeats the point.

---

## quick-meet-window
Drinks within the current trip / week. Casual, no pretense of long-term.
Compresses rapport phase. Pushes logistics earlier.

## flexible-short-window
Meet if it clicks. No timeline pressure either way. Default for
ambiguous matches in the current city.

## extended-window
Willing to invest more time across messages. Still casual; not LTR.
Appropriate when both people are local and not on a hard timer.

## just-being-polite
Not pursuing, but not ghosting either. Low-frequency replies, no
investment. Used when interest has dropped but a hard close isn't
warranted.

## decline-gracefully
Actively winding down. Polite, brief, no door left open. Used when
goals have diverged and continuing would mislead.

## reconnect-later
She's leaving / I'm leaving and there's a real possibility of
overlap in a future city. Keep the door open without active pursuit.

## platonic-curiosity
Match is interesting as a person but romantic interest has faded
from one or both sides. Optional; only adopt if she's surfaced it
explicitly.
